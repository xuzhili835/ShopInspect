# ShopInspect 缺陷处置 SOP · 总则

## 1. 编制目的与适用范围
本套 SOP(标准作业程序)为车间质检台 ShopInspect 的缺陷处置知识库,覆盖 NEU-DET 数据集定义的六类热轧带钢表面缺陷。检测模型(`def_best.pt`)识别出缺陷类别后,处置模块(rag_agent)按本 SOP 检索对应处置规程,生成多步处置方案;涉及停机、判废等高危动作时须人工确认(HITL)后方可执行。

## 2. 编制依据
1. **GB/T 14977-2008《热轧钢板表面质量的一般要求》**,全国钢标准化技术委员会归口——表面质量分类分级、按缺陷深度/面积判定的框架依据(该版已被 GB/T 14977-2025 代替,分级思路沿用)。标准详情 · 全国标准信息公共服务平台: https://std.samr.gov.cn/gb/search/gbDetailed?id=71F772D78682D3A7E05397BE0A0AB82A
2. **热轧带钢异物压入缺陷分析及改进措施**,《金属世界》2021 年第 1 期(宝钢 1580mm 产线)。DOI: 10.3969/j.issn.1000-6826.2021.01.0013。期刊官网全文: https://metalworld.ustb.edu.cn/cn/article/pdf/preview/10.3969/j.issn.1000-6826.2021.01.0013.pdf
3. **热轧钢板典型压入式氧化铁皮的分类及其形成机理**,《东北大学学报(自然科学版)》——浅层压入式/嵌入式两类压入缺陷的形成机理。学报官网全文: https://xuebao.neu.edu.cn/natural/CN/article/downloadArticleFile.do?attachType=PDF&id=1469
4. **热轧板带氧化铁皮产生的原因和控制措施**,《轧钢》(首钢京唐产线实践)——氧化铁皮缺陷成因分类与控制措施。期刊官网: http://www.chinarolling.com/gyby/zg/CN/10.13228/j.boyuan.issn1003-9996.20170102
5. **Song K, Yan Y.** A noise robust method based on completed local binary patterns for hot-rolled steel strip surface defects. *Applied Surface Science*, 2013, 285(B): 858-864. DOI: 10.1016/j.apsusc.2013.09.002: https://doi.org/10.1016/j.apsusc.2013.09.002——NEU-DET 数据集原始文献。

> 说明:缺陷界限的具体数值(允许深度、面积、修磨余量比例)依各企业评级标准与订单表面等级执行,本 SOP 给出通用框架与典型做法。

## 3. 数据集背景
NEU-DET 由东北大学机械工程与自动化学院宋克臣团队发布,含热轧带钢表面缺陷图像 1800 张(200×200 灰度,六类各 300 张),是表面缺陷检测研究的公开基准数据集。数据集官方页面 · 东北大学: http://faculty.neu.edu.cn/songkechen/zh_CN/zdylm/263270/list/

## 4. 各分则处置通则
1. **先评级、后处置**:按缺陷深度/面积/分布对照表面等级定级,再执行对应处置档。
2. **分级处置路径**:轻微 → 修磨/酸洗等表面处理;一般 → 处理后降级评估;严重 → 判废/改判,并视伤源决定是否停机检修。
3. **可追溯**:每次处置记录缺陷类别、位置、评级、处置手段与结果,关联检测记录编号。
4. **根因反馈**:同类缺陷批量或连续出现,必须回溯上游工序(炼钢/加热/除鳞/轧制/辊系),不能只处理单件。
5. **高危动作人工把关**:停机、停线、判废、停产、更换设备件等动作,由 Agent 生成建议、质检人员确认后执行并留痕。

## 5. 分则目录
scratches(划痕)/ crazing(龟裂)/ inclusion(夹杂物)/ patches(斑块)/ pitted_surface(麻点)/ rolled-in_scale(氧化铁皮压入)。每篇分则结构:定义与外观特征 → 成因机理 → 检测与评级 → 分级处置 → 复检验收 → 根因反馈与预防 → 参考文献。

## 6. 缺陷类别与参考资料对应关系

> **重要说明**:GB/T 14977 为分级判定总纲(A、B 两类,每类 1–3 级,按缺陷深度/面积判定修磨或判废),**不提供缺陷分类命名**;六类缺陷命名与样本定义出自 NEU-DET 数据集文献。二者的衔接映射由本 SOP 完成——见下表。

| 类别(NEU-DET) | 定义出处 | 成因机理参考 | 处置/分级依据 |
|---|---|---|---|
| crazing 龟裂 | NEU-DET 文献[5] | 文献描述 + 行业通用工艺认知(铸坯裂纹/结晶器渗铜/加热制度) | GB/T 14977 分级总纲 + 热轧通用处置做法 |
| inclusion 夹杂物 | NEU-DET 文献[5] | 《金属世界》异物压入研究(非金属物轧入表面,同类机理) | 同上 |
| patches 斑块 | NEU-DET 文献[5] | 《轧钢》氧化铁皮成因与温度制度研究 | 同上 |
| pitted_surface 麻点 | NEU-DET 文献[5] | 《东北大学学报》压入式氧化铁皮机理(压入-脱落成坑) | 同上 |
| rolled-in_scale 氧化铁皮压入 | NEU-DET 文献[5] | 《东北大学学报》+《轧钢》(与压入式氧化铁皮直接对应) | 同上 |
| scratches 划痕 | NEU-DET 文献[5] | 文献描述 + 行业通用认知(导卫/辊道刮擦);《金属世界》涉及辊道异物来源 | 同上 |

其中[5]=Song K, Yan Y. Applied Surface Science, 2013, 285(B): 858-864, DOI: 10.1016/j.apsusc.2013.09.002。

## 7. 参考文献与来源说明
1. **链接格式**:全部出处为裸链接(URL 直接可见),可直接复制到浏览器打开,来源统一为:国家标准官方平台、期刊官方网站(《金属世界》《东北大学学报》《轧钢》)、国际期刊 DOI、东北大学数据集官方页面。
2. **来源定位说明**:公开渠道不存在按缺陷类别统一发布维修 SOP 的网站——真实处置 SOP 属企业内部工艺标准(不对外公开);国标(GB/T 14977)仅规定表面质量的分类分级与验收判定,期刊文献提供成因机理研究。因此本套 SOP 系依据上述公开资料整理编制的企业式结构文档,生产部署时替换为企业真实维修手册与评级标准,检索管道无需改动。
