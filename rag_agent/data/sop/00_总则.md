# ShopInspect 缺陷处置 SOP · 总则

## 1. 编制目的与适用范围
本套 SOP(标准作业程序)为车间质检台 ShopInspect 的缺陷处置知识库,覆盖 NEU-DET 数据集定义的六类热轧带钢表面缺陷。检测模型(`def_best.pt`)识别出缺陷类别后,处置模块(rag_agent)按本 SOP 检索对应处置规程,生成多步处置方案;涉及停机、判废等高危动作时须人工确认(HITL)后方可执行。

## 2. 编制依据
- **GB/T 14977-2008《热轧钢板表面质量的一般要求》**(全国钢标准化技术委员会归口;按表面质量分类分级、以缺陷深度/面积判定的框架思想编制;该版已被 GB/T 14977-2025 代替,分级思路沿用)。
- 宝钢 1580mm 产线热轧带钢异物压入缺陷分析与改进措施(《金属世界》2021 年第 1 期,DOI: 10.3969/j.issn.1000-6826.2021.01.0013)。
- 首钢迁钢 2160mm 产线热轧薄板氧化铁皮类缺陷形成机理与控制研究。
- 《热轧带钢表面凹坑缺陷成因分析与预防》(期刊文献)。
- 热轧酸洗钢卷生产流程工艺资料。

> 说明:缺陷界限的具体数值(允许深度、面积、修磨余量比例)依各企业评级标准与订单表面等级执行,本 SOP 给出通用框架与典型做法。

## 3. 数据集背景
NEU-DET 由东北大学宋克臣团队发布(faculty.neu.edu.cn/songkechen),含热轧带钢表面缺陷图像 1800 张(200×200 灰度,六类各 300 张),是表面缺陷检测研究的公开基准数据集;原始提出论文:Song K, Yan Y. A noise robust method based on completed local binary patterns for hot-rolled steel strip surface defects. Applied Surface Science, 2013.

## 4. 各分则处置通则
1. **先评级、后处置**:按缺陷深度/面积/分布对照表面等级定级,再执行对应处置档。
2. **分级处置路径**:轻微 → 修磨/酸洗等表面处理;一般 → 处理后降级评估;严重 → 判废/改判,并视伤源决定是否停机检修。
3. **可追溯**:每次处置记录缺陷类别、位置、评级、处置手段与结果,关联检测记录编号。
4. **根因反馈**:同类缺陷批量或连续出现,必须回溯上游工序(炼钢/加热/除鳞/轧制/辊系),不能只处理单件。
5. **高危动作人工把关**:停机、停线、判废、停产、更换设备件等动作,由 Agent 生成建议、质检人员确认后执行并留痕。

## 5. 分则目录
 scratches(划痕)/ crazing(龟裂)/ inclusion(夹杂物)/ patches(斑块)/ pitted_surface(麻点)/ rolled-in_scale(氧化铁皮压入),每篇分则结构:定义与特征 → 成因机理 → 检测与评级 → 分级处置 → 复检验收 → 根因反馈与预防 → 参考文献。
