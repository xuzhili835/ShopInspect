# 龟裂(crazing)缺陷处置 SOP

## 1. 定义与外观特征
带钢表面密集网状/龟壳状细微裂纹,裂纹浅而密、肉眼可见纹理;严重时呈带状或大面积分布。低倍酸浸或渗透探伤可确认范围与是否向基体延伸。

## 2. 成因机理
根源多在铸坯与加热环节:① 连铸结晶器铜板渗铜在铸坯表面富集,热轧时形成表面网裂(经典成因);② 铸坯坯壳纵/横裂纹经轧制延展铺开成网状;③ 加热炉温度不均或局部过烧导致表面开裂。缺陷在轧制中被拉长、铺展,形成大面积龟裂纹。

## 3. 检测与评级
目视初筛 → 渗透/酸浸确认深度与范围;按网纹密度、分布面积及是否延伸基体评级(界限按企业标准执行);同炉批集中出现时按炉号追溯。

## 4. 分级处置
分级框架参照 GB/T 14977(分类分级、按深度/面积判定;具体界限按企业标准执行):
- **局部浅层**(未向基体延伸):修磨去除裂纹层,修磨量受控;修磨后渗透复检无显示。
- **大面积/成带分布**:该段【判废】或降级改作非表面等级用途。
- **疑似过烧**(伴随性能异常):该炉批【停线】排查加热制度,加做性能与金相检验。

## 5. 复检验收
修磨区渗透探伤无裂纹显示;网纹完全去除且修磨量未超余量;硬度抽查无异常;改判用途须满足对应订单等级。

## 6. 根因反馈与预防
成批出现优先反馈:炼钢连铸(结晶器铜板状态与镀层、二冷制度、保护浇铸)与加热炉(各段温度、在炉时间、炉内气氛);按炉号关联浇次记录溯源,整改后连续跟踪。
