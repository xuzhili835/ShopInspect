# 龟裂(crazing)缺陷处置 SOP

## 症状识别
表面出现密集的网状、蜘蛛网状细微裂纹,常因热应力、组织应力或表面脱碳引起。裂纹浅而密,肉眼可见网纹。

## 处置步骤
1. 全区清洁后用低倍放大镜 / 渗透探伤(PT)确认裂纹范围与深度。
2. 测量单条裂纹长度与网格密度,拍照存档。
3. 局部浅层龟裂:用砂轮 / 油石轻微修磨去除裂纹层,修磨量 ≤ 0.2mm,再渗透复检。
4. 范围较大或裂纹向基体延伸:禁止继续使用,转技术评估。

## 严重度分级
- 轻度:局部网纹,修磨可去除,渗透复检无显示。
- 中度:多区域龟裂,需评估疲劳影响。
- 重度:裂纹扩展至基体或大面积分布,【停机/换件】(高危,需人工确认)。

## 复检标准
修磨区渗透探伤(PT)无裂纹显示;表面无网纹;尺寸符合公差。关键件需补充硬度检测。
