# 氧化铁皮压入(rolled-in_scale)缺陷处置 SOP

## 1. 定义与外观特征
灰黑/蓝黑色片状、鱼鳞状氧化铁皮层嵌入带钢表面,沿轧向呈条状/片状分布,边缘翘起或脱落后留下凹坑;酸洗后残留坑状痕迹的深浅可判断压入深度。

## 2. 成因机理
① 加热炉生成的初生氧化铁皮未被除净——高压除鳞水压力不足、喷嘴堵塞或角度偏(首钢迁钢 2160 线研究系统分析了氧化铁皮类缺陷形成机理);② 轧制过程温升再生的次生氧化皮被后续道次压入;压入深度超过酸洗能力时脱落后成麻面。

## 3. 检测与评级
目视 + 酸洗试验判断压入深度(酸洗后是否残留痕迹);按分布面积与压入深度评级(界限按企业标准执行);带状分布提示除鳞喷嘴局部遮挡。

## 4. 分级处置
分级框架参照 GB/T 14977(分类分级、按深度/面积判定;具体界限按企业标准执行):
- **浅表压入**(酸洗可去除):按酸洗工艺正常处理,酸洗后按原等级放行。
- **压入较深**(酸洗后残留麻面):局部修磨 + 抛光,按表面等级降级评估。
- **大面积深压入**:该段【判废】;确认除鳞系统故障(水压读数、喷嘴堵塞)时【停线】检修除鳞箱,恢复后首卷加严检验。

## 5. 复检验收
酸洗后表面无残留皮层与坑状痕迹;色泽均匀;表面等级复评通过;除鳞参数(水压/喷嘴状态)记录在案。

## 6. 根因反馈与预防
反馈加热炉(出炉温度、在炉时间——控制初生皮厚度)与除鳞箱(高压水压力、喷嘴点检周期、角度校准);压入呈带状时排查喷嘴遮挡;结合氧化铁皮机理研究优化除鳞制度。
