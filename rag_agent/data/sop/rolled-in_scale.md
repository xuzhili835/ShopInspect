# 氧化铁皮压入(rolled-in_scale)缺陷处置 SOP

## 症状识别
表面压入灰黑色氧化铁皮,呈片状、条状或点状嵌入基体,常沿轧制方向分布,脱落后留下凹坑。

## 处置步骤
1. 记录压入面积、深度与分布,拍照存档。
2. 判断氧化皮是否已脱落(留下凹坑)或仍嵌入。
3. 嵌入较浅:酸洗 + 抛光去除氧化皮及表面层。
4. 深度压入或脱落后凹坑明显:精磨找平,复测尺寸。

## 严重度分级
- 轻度:浅表压入,酸洗抛光可去除。
- 中度:局部压入伴浅坑,精磨处理。
- 重度:大面积深压入,【换件】(高危,需人工确认)。

## 复检标准
表面无氧化皮残留与凹坑;色泽均匀;尺寸在公差。反馈除鳞 / 轧制工序加强氧化皮控制。
