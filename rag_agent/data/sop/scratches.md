# 划痕(scratches)缺陷处置 SOP

## 症状识别
钢材/工件表面出现线状、条状机械划伤痕迹,长度与方向不一,通常由搬运、接触摩擦或模具磨损造成。外观为连续或断续的浅沟。

## 处置步骤
1. 标记划痕起止位置与方向,拍照存档(关联工单号/批次号)。
2. 用表面粗糙度仪或千分尺测量划痕深度,判定严重度。
3. 轻度划痕(<10μm):使用 800→1200 目砂纸沿同一方向逐级打磨抛光,消除毛刺。
4. 中度划痕(10–50μm):先油石研磨找平,再抛光;打磨后做尺寸复测。
5. 深划痕(>50μm)或位于关键受力区:禁止打磨,转维修工单评估补焊或换件。

## 严重度分级
- 轻度:深度 < 10μm,不影响功能,抛光放行。
- 中度:深度 10–50μm,研磨 + 抛光 + 复检。
- 重度:深度 > 50μm 或位于配合面/密封面,【换件】(高危,需人工确认)。

## 复检标准
打磨区粗糙度 Ra ≤ 1.6μm;尺寸在公差内;目视无可见沟痕。复检合格方可放行,记录归档。
