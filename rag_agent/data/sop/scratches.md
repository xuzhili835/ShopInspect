# 划痕(scratches)缺陷处置 SOP

## 成因与来源
机械划伤:坯料在辊道输送、导卫装置、夹送辊、卷取及吊运环节与硬物刮擦;导卫/辊面粘附氧化铁皮碎屑或磨损掉肉,在带钢表面拉出连续或断续的沟状伤痕。

## 症状识别
线状/条状机械伤痕,方向多与轧向一致,长短不一,深度可用测厚或着色渗透评估;连续成排出现时优先怀疑辊系或导卫存在固定伤源。

## 评级与分级处置
分级框架参照 GB/T 14977《热轧钢板表面质量的一般要求》(表面质量分类分级、按缺陷深度/面积判定;具体界限值按企业标准与订单表面等级执行):
按划痕深度与订单表面等级分级(具体界限按企业评级标准执行):
- 轻微(浅表,深度在允许修磨余量内):砂带/砂轮局部修磨后抛光,修磨量与板厚比例控制在标准范围内。
- 一般(修磨可去除但面积较大):连续修磨 + 局部抛光,修磨后测厚确认未超负偏差。
- 严重(深度超标或成排复现):该段【判废】或降级改判;若确认辊系/导卫伤源,【停机】检查更换受损辊或导卫件。

## 复检标准
修磨区目视无可见沟痕,着色/渗透探伤无裂纹显示;测厚在产品负偏差内;修磨痕迹过渡圆滑。

## 根因反馈
追溯该卷前后卷是否同位置复现:同位置复现→检查对应辊位/导卫;随机分布→检查吊运与仓储环节。辊面硬度、导卫间隙纳入点检。
