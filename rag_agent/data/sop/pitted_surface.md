# 麻点(pitted_surface)缺陷处置 SOP

## 症状识别
表面密集分布细小凹坑(麻点),点状、不规则,常由氧化皮压入后脱落、酸洗过度或腐蚀造成。

## 处置步骤
1. 统计麻点密度与单坑直径,拍照存档。
2. 测量凹坑深度(粗糙度仪 / 千分尺)。
3. 轻微麻点:抛光降低表面粗糙度,消除凹坑影响。
4. 深麻点或密集分布:评估对疲劳 / 配合的影响,必要时精磨去除表层。

## 严重度分级
- 轻度:零星浅坑,抛光放行。
- 中度:局部密集,精磨 + 复检。
- 重度:大面积深坑影响配合面,【换件】(高危,需人工确认)。

## 复检标准
表面粗糙度达标;无密集凹坑;配合尺寸在公差内。关键件做疲劳评估记录。
