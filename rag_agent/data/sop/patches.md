# 斑块(patches)缺陷处置 SOP

## 1. 定义与外观特征
带钢表面不规则片状/块状色差或组织异常区域,与基体边界清晰,手感多无凹凸;可呈岛状或带状分布。需区分单纯外观色差与伴随组织异常(过热区)两类。

## 2. 成因机理
加热与轧制过程温度不均导致局部氧化程度差异、除鳞不净残留局部氧化膜,轧后呈现边界明显的斑块状外观;严重时伴随局部组织异常(晶粒粗大、硬度偏离),影响性能而不仅是外观。

## 3. 检测与评级
目视测定分布与面积;硬度对比抽查判断是否伴随组织异常(斑块区与正常区硬度差);按面积占比与是否伴随组织异常评级(界限按企业标准执行)。

## 4. 分级处置
分级框架参照 GB/T 14977(分类分级、按深度/面积判定;具体界限按企业标准执行):
- **仅外观色差、硬度正常**:酸洗/抛丸去除表层氧化后,按原等级或降半级放行。
- **伴随组织异常**(硬度偏离、晶粒粗大):该段降级或【判废】;伴随性能不合时不得改充表面等级订单。

## 5. 复检验收
酸洗后表面色泽均匀;硬度抽查在产品规格范围内;按订单表面等级复评通过并留档。

## 6. 根因反馈与预防
反馈加热炉(各段温度均匀性、在炉时间)与轧制温度制度;斑块呈规律性分布时排查水冷边遮挡与除鳞局部盲区;定期做炉温均匀性测试(黑匣子测试)。
