# 斑块(patches)缺陷处置 SOP

## 成因与来源
片状/块状色差或组织异常区:加热与轧制温度不均导致局部氧化程度差异、除鳞不净残留局部氧化膜,轧后呈现与基体边界明显的斑块状外观差异。

## 症状识别
不规则片状、块状色差区域,边界清晰,手感多无凹凸;硬度对比可辅助判断是否伴随组织异常(过热区硬度偏离)。

## 评级与分级处置
分级框架参照 GB/T 14977《热轧钢板表面质量的一般要求》(表面质量分类分级、按缺陷深度/面积判定;具体界限值按企业标准与订单表面等级执行):
- 仅外观色差、硬度正常:酸洗/抛丸去除表层氧化后按原等级或降半级放行。
- 伴随组织异常(硬度偏离、晶粒粗大):该段降级或【判废】;伴随性能不合时不得改充表面等级订单。

## 复检标准
酸洗后表面色泽均匀;硬度抽查在产品规格范围内;按订单表面等级复评。

## 根因反馈
反馈加热炉(各段温度均匀性、在炉时间)与轧制温度制度;斑块呈规律性分布时排查水冷边/除鳞遮挡。
