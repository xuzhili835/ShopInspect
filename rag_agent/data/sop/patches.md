# 斑块(patches)缺陷处置 SOP

## 症状识别
表面出现片状、块状色差或纹理异常区域,与周围基体有明显边界,常见于轧制氧化不均或温度不均。

## 处置步骤
1. 测量斑块面积与位置,拍照存档。
2. 用硬度计对比斑块区与正常区硬度差异。
3. 浅表色差斑块:酸洗或轻度抛光去除氧化层,恢复均匀外观。
4. 硬度异常或组织异常斑块:取样金相分析,不可直接放行。

## 严重度分级
- 轻度:仅外观色差,硬度正常,酸洗/抛光放行。
- 中度:局部硬度偏差,需金相确认。
- 重度:大面积组织异常,【换件】(高危,需人工确认)。

## 复检标准
表面色泽均匀;硬度在规格内;金相组织正常。记录斑块成因,反馈轧制工序。
