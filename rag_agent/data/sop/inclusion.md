# 夹杂物(inclusion)缺陷处置 SOP

## 症状识别
表面或近表面存在非金属夹杂物(氧化物、硫化物等),呈点状、条状暗色斑,常沿轧制方向分布,可能伴随凹坑。

## 处置步骤
1. 记录夹杂物位置、数量、尺寸,拍照存档。
2. 金相 / 能谱确认夹杂物类型与来源(冶炼 / 轧制)。
3. 单个细小夹杂:局部修磨去除,修磨深度 ≤ 0.3mm,复测尺寸。
4. 大型或密集夹杂:不可修磨去除,转工艺追溯炉号批次。

## 严重度分级
- 轻度:单个 < 0.2mm,修磨去除放行。
- 中度:多处夹杂,需批次追溯。
- 重度:条状夹杂 > 1mm 或密集分布,【报废/换件】(高危,需人工确认)。

## 复检标准
修磨区无可见夹杂;表面平整;批次质量追溯记录归档。同一炉号多次出现需上报工艺。
