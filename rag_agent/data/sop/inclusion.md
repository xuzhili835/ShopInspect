# 夹杂物(inclusion)缺陷处置 SOP

## 1. 定义与外观特征
非金属夹杂物暴露于带钢表面形成的点状、短线状或条状暗色斑,常沿轧向断续排布,周边可伴脱落凹坑;金相与能谱分析可确认夹杂类型与来源(脱氧产物/耐材/渣类),是判别成因与责任工序的关键。

## 2. 成因机理
炼钢脱氧产物、中间包与结晶器耐材剥落、保护浇铸不良卷入的夹渣,随铸坯进入轧制后被延展拉长,暴露于成品表面;宝钢 1580 线研究将异物压入归纳为清坯毛刺掉落、锈蚀物脱落轧入等多类来源,均指向上游工序洁净度。

## 3. 检测与评级
目视 + 金相/能谱定性;按数量、尺寸、分布密度对照表面等级评级(界限按企业标准执行);同炉号多卷出现即触发工艺追溯。

## 4. 分级处置
夹杂无法靠修磨根治(去除表层后内层仍可能再现),以评级判级为主:
- **单个细小、数量在等级内**:按相应表面等级放行或降一级交付。
- **密集分布或条状超长**:该段【判废】。
- **同炉号批量出现**:该浇次【停产】追溯,未查明原因前暂缓同工艺批次交付。

## 5. 复检验收
按炉批抽查复评,表面等级满足订单要求;金相定性记录存档;整改后首件加严检验。

## 6. 根因反馈与预防
反馈炼钢工序:脱氧制度、中包/结晶器耐材寿命管理、保护浇铸氩封状态;区分耐材类与脱氧类夹杂对症整改;建立炉号-浇次-缺陷对应台账。
